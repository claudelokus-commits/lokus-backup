Lokus Backup

A private, personal backup tool.

Lokus Backup copies files from its owner's own computer to the owner's own Google Drive, using the open-source program rclone. It is used by one person only and is not offered to the public.

Privacy Policy

Lokus Backup is used only by its owner, with the owner's own Google account.

  • It does not collect, store, share or sell personal data of any other person.
  • Access to Google Drive is used only to upload, read and organize the owner's own backup files inside the owner's own Google Drive.
  • Data obtained through Google APIs is not transferred to anyone and is not used for any other purpose, including advertising or analytics.
  • The tool has no server of its own. Files travel directly between the owner's computer and Google Drive.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions can be sent to the support email address shown on the app's Google sign-in screen.
